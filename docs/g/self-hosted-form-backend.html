A Formspree alternative you actually own

Form backends are the simplest paid API on the internet: accept a POST, store it, optionally fire a webhook. Formspree charges $10+/month for that.

The self-hosted version

FormDock gives you a form endpoint, submission storage, a spam flag, auto-retention (7/30/90 days — GDPR-friendly), and per-form webhooks that POST each submission as JSON to any URL (Slack, Zapier, your own app).

Deploy

docker build -t formdock app/
docker run -d -p 8000:8000 -v formdock-data:/data formdock

Point your static site's <form action> at it. Done.
