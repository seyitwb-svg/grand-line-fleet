Agent-payable fetch & token APIs: x402 endpoints that settle direct on Base

AI agents that need web data or token lookups can pay per call instead of signing up for an API plan. These endpoints answer HTTP 402 with a unique jittered amount and order id; your agent pays exact USDC on Base, retries with the tx hash, and gets the result. No account, no API key, no facilitator — settlement is verified straight against a public Base RPC.

/x402/pagescan — fetch + parse any URL (~$0.005)

Returns page title, meta description, link list and a clean text excerpt of any public URL. Fetched server-side with no JavaScript and no redirect following; private, link-local and reserved hosts are refused at DNS time.

GET {goldshop}/x402/pagescan?url=https://example.com

Try it free first — one demo call per client proves delivery before an agent spends anything:

GET {goldshop}/x402/free/pagescan?url=https://example.com

/x402/tokeninfo — ERC-20 info on Base (~$0.005)

Reads a token contract straight off the chain via eth_call: name, symbol, decimals, total supply and contract bytecode size. Works on any Base contract, including non-standard bytes32-returning tokens.

GET {goldshop}/x402/tokeninfo?address=0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913

/x402/verify — settlement attestation (~$0.002)

Did a given transaction pay at least min to to? Works on Base (USDC units), bitcoin (sats) and tron (USDT-TRC20 atomic units). Useful when an agent needs independent confirmation before trusting a payment claim.

GET {goldshop}/x402/verify?tx=<txhash>&to=<recipient>&min=<units>&chain=base

The payment model in one paragraph

Each 402 response carries a unique jittered amount (amount in the accepts entry) plus an orderId. Paying exactly that amount to payTo and retrying with X-PAYMENT set to the transaction hash redeems the order. The transaction can only be claimed once — replays get an idempotent re-serve of the same result instead of a double-spend. Full resource directory: /.well-known/x402 on the store.
