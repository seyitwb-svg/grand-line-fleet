# How it works Every product runs the same shape: - **Non-root container**, read-only filesystem, 256 MB memory cap, restart unless-stopped - **SQLite** on a per-app volume, backed up nightly via `sqlite3 .backup` (restore-drilled) - **Health probe** every 2 minutes → bounty board - **Tunnel watchdog** syncs the public URL when Cloudflare reassigns it - **Owner webhooks** — every product can POST key events (new signup, booking, quote accepted, monitor down) to a Slack/Discord hook - **Self-testing**: each app carries a Playwright E2E suite; a full sweep is 14/14 green Total footprint: ~600 MB RAM across 14 services.
