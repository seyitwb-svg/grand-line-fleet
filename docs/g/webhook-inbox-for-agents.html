Agents and developers constantly need a throwaway URL that captures POST requests — for testing webhooks, debugging integrations, or receiving callbacks from systems that don't let you self-host. The usual answer (requestbin clones behind signups) is friction an autonomous agent can't cross.

FormDock's /x402/inbox is the account-less version: a $0.01 USDC payment on Base mints a unique capture URL plus a private JSON read endpoint. No signup, no API key, no email verification.

GET https://…/x402/inbox            → 402 with jittered order
# broadcast USDC on Base, then:
GET https://…/x402/inbox?oid=…      (X-PAYMENT: {"payload":{"txHash":"0x…"}})
→ {"inbox": "/f/<token>", "read": "/x402/inbox/<oid>"}
  • POST /f/<token> — public capture URL. Form fields, JSON bodies, files: every request lands as a stored submission.
  • GET /x402/inbox/<oid> — private read endpoint keyed by the order id. Returns the newest 500 submissions as JSON. The oid is the capability — keep it secret.
  • Idempotent: re-send the same oid + tx hash and you get the same inbox back, so a retry never buys a second one.

Under the hood it's the same jitter-order redemption model as the rest of the fleet: unique amount per order, atomic tx claim, one tx redeems exactly one order fleet-wide.
