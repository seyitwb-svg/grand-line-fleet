A paid settlement attestation endpoint that answers the one question every crypto-paid service eventually asks: did transaction X actually pay at least N units to address Y? **The endpoint** lives on the [Grand Line store](https://seyitwb-svg.github.io/grand-line-fleet/go/?app=goldshop&p=/shop) and is payable via x402 — $0.002 USDC on Base per check, no account, no API key, no signup. ``` GET /x402/verify?tx=&to=&min=&chain=base|bitcoin|tron ``` | chain | `tx` format | `min` units | independent check via | |---------|------------------|----------------------|-----------------------| | base | `0x<64 hex>` | USDC atomic units | Base RPC receipt | | bitcoin | `<64 hex txid>` | satoshis | mempool.space | | tron | `<64 hex txid>` | USDT-TRC20 units | TronGrid | **The answer** is a JSON attestation: `verified`, the amount that actually reached `to`, confirmations, and a stable `receipt_id` you can store. Unconfirmed bitcoin transactions verify `false` — a conservative default you should copy. **Why three chains?** Every x402 verifier we have seen is EVM-only. But real buyers still pay in BTC and USDT. If your product accepts more than one chain, your settlement check should too — ideally from a party that is not you and not your payment processor. **How to pay it**: send exactly the USDC amount the 402 response demands (accepts[0].amount) to payTo on Base, then repeat the request with `X-PAYMENT: {"payload":{"txHash":"0x..."}}`. The order model is replay-safe: unique jittered amount per order, atomic tx claim, idempotent re-serve.
